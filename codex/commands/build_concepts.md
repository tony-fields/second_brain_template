# Build Concepts

Scan all papers in papers/.

Identify recurring concepts such as:
- LWE
- VRF
- Schnorr
- Blind Signatures

For each concept:
1. Create a file in concepts/ if it does not exist
2. Add:
   - Definition
   - Key ideas
   - Linked papers

Use format:
# Concept Name

## Definition
## Key Ideas
## Related Papers
